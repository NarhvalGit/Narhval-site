# Narhval site

Een statische one-pager voor Narhval met drie gelinkte domeinpagina's (Learning, Advies en Software). Alles gebruikt de Narhval-kleuren en accentlijnen.

## Gebruik
Open `index.html` in je browser. De knoppen verwijzen naar de drie subpagina's die je verder kunt invullen met eigen inhoud en formulieren.
